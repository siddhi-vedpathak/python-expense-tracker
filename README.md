# Python Expense Tracker

A simple CLI-based Expense Tracker built with Python to manage daily personal expenses.

## Features
- Add new expenses with date, category, description, and amount.
- View a complete list of recorded expenses.
- Calculate total money spent.
- Find the single highest expense.

## Tech Stack
- Python 3

## How to Run
1. Clone this repository:
   git clone https://github.com/siddhi-vedpathak/python-expense-tracker.git
2. Navigate to the directory:
   cd python-expense-tracker
3. Run the script:
   python main.py
